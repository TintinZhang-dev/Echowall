# Phewall 管理员审核操作手册 v1.0

> 给管理员（含学长 admin1）的操作指南。核心原则：**所有处理按协议执行、记录原因、可被申诉**。
> 协议全文：/terms · 举报规则：5次自动隐藏 / 涉及自己立即隐藏

## 一、接到举报后（3个工作日内审核）

1. 看"举报管理"页 → 帖子/评论举报（带类型徽章）
2. 判断是否违规（对照协议第四条）：
   - 明显违规（辱骂/谣言/隐私/广告）→ 隐藏或删除，写原因
   - 涉及自己举报（原因带"涉及自己"）→ 已自动隐藏，审核是否属实：
     - 属实 → 维持隐藏或删除
     - 明显恶意滥用 → 恢复 + 按协议第十条处罚举报人
   - 不违规（正常内容被恶意举报）→ 恢复显示
3. 每次操作记录原因（后台自动记日志）

## 二、处罚标准（协议第十条）

| 情节 | 处理 |
|------|------|
| 轻微不当言论 | 隐藏/删除 + 警告 |
| 辱骂/引战/谣言（首犯） | 删除 + 封禁账号 3 天 |
| 90日内再犯 | 封禁 7 天 |
| 第三次及以上 | 封禁 30 天 |
| 人肉/恶意骚扰/冒用身份/恶意举报 | 封禁 30 天，必要时临时IP封禁（≤30日） |
| 违法内容/情节特别严重 | 永久封禁账号（慎用，先和创始人确认） |

⚠️ IP 封禁仅限：技术上判断为个人独享IP + 紧急风险，时长 ≤30 日，避免误伤校园网共用IP。

## 三、处理流程铁律

1. 删帖/隐藏/封禁 → 后台操作 + 原因必填
2. 被处理人申诉 → 3个工作日内复核
3. 涉及他人的内容 → 被涉及人举报后无论内容如何先隐藏（隐私优先），再审核
4. 拿不准的 → 问创始人，不要自己拍板

## 四、公示

所有操作记录在"操作日志"页，对全体用户公示（透明化承诺）。
