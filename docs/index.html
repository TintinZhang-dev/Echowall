✨ 能做什么

📝 发帖与互动

文字 / 图片 / 视频 / Word 投稿，匿名或实名；点赞、评论、转发、关注、私信。

🗂️ 分区板块

板块列表由配置驱动，开学初一套预置，之后可自由增删。

🏅 积分等级

仿 B 站经验值，防刷上限 + 可审计流水；等级解锁彩色昵称、置顶等特权。

🛡️ 内容治理

举报（账号去重 + 自动隐藏）、申诉、IP 封禁、管理员操作日志。

🔐 账号体系

JWT（httpOnly cookie）；"届 / 班"体系可选开关，外校或社会版可关掉。

☁️ 媒体存储

Cloudflare R2，对象键按校前缀隔离；Word 附件三层防宏病毒校验。

📱 PWA + App

网页可"添加到主屏幕"；每校独立包名 / 图标 / 签名 keystore 的 TWA APK。

⚡ 一键开通

provision-school.sh：从校名 / 域名生成配置、keystore、APK 与部署清单。

🏗️ 技术栈

Node.jsExpressSQLite (better-sqlite3, WAL) 纯 HTML / CSS / JSCloudflare R2 Cloudflare Tunnelpm2Bubblewrap / TWA

🚀 本地跑起来

git clone https://github.com/TintinZhang-dev/Echowall.git
cd Echowall
npm install
cp site.config.example.json site.config.json   # 按需修改校名/域名/板块
npm run init-site                               # 初始化板块 + 欢迎帖（幂等）
JWT_SECRET=change-me npm start                 # http://localhost:3000
